# Dourbia - Landing Page

Landing page officielle de **DOURBIA**, plateforme de visites culturelles à la carte en Tunisie.

## Technologies

- React 19
- Vite
- CSS personnalisé (design fidèle au PDF)

## Lancer le projet

```bash
npm install
npm run dev
```

Le site sera accessible sur `http://localhost:5173`

## Build production

```bash
npm run build
npm run preview
```

## Sections

- Header avec navigation
- Hero avec carousel (WhatsApp 1-4) et filtres Destination / Durée
- TOP Destinations (Carthage, La Marsa)
- Features (Guide Numérique, Packs, Circuits)
- Démo application mobile
- Packages de services
- Témoignages
- Footer
